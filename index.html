Objetivo

Desenvolver e validar um launcher de mods capaz de centralizar e simplificar o gerenciamento de modificações para jogos digitais, permitindo ao usuário instalar, organizar, atualizar e iniciar diferentes configurações de mods de forma prática e segura.

Desenvolvimento

O Mcore: Modcore será desenvolvido para facilitar o gerenciamento de mods, permitindo pesquisar, instalar, atualizar e organizar modificações em um único sistema. A plataforma terá perfis de configuração, verificação de compatibilidade e uma interface simples. Será utilizada uma arquitetura com frontend, backend, API REST e banco de dados. Por fim, serão realizados testes para verificar o funcionamento e a facilidade de uso do sistema.

Conclusão

O Mcore: Modcore busca facilitar o gerenciamento de mods, tornando a instalação, organização e atualização mais simples. O projeto também permite aplicar conhecimentos de desenvolvimento de software em uma solução prática e que pode receber novas funcionalidades no futuro.
